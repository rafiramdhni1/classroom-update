Backend Developer & Security

Logika Server, REST API & Keamanan Data

Express + JWT

Tanggung Jawab Utama:

  • Membangun arsitektur server Express.js dan pipeline middleware di server.js.
  • Mengembangkan otentikasi **JWT** dan hashing password satu arah dengan **bcryptjs**.
  • Menerapkan sistem hak akses **RBAC** (adminOnly, staffOnly).
  • Menerapkan validasi input skema dengan **Zod** dan perlindungan **Multi-Tier Rate Limiting**.

File & Modul yang Dipegang:

backend/server.js middleware/auth.js routes/auth.js routes/grades.js
🎤 Giliran Presentasi (Arsitektur API & Keamanan) 3–4 Menit

Menjelaskan bagaimana API melindungi data sekolah: enkripsi password, cara token JWT memvalidasi role siswa/guru tanpa beban session server, serta proteksi rate-limiting dari serangan brute-force.

Database & API Integrations

MongoDB, Google Classroom & Bot Telegram

MongoDB + APIs

Tanggung Jawab Utama:

  • Merancang skema **8 koleksi MongoDB** (`User`, `Student`, `Grade`, `CourseworkCache`, dsb).

  • Membuat daemon **Bot Telegram** (`bot-poll.js`) untuk aktivasi akun dan reset sandi via OTP.
  • Mengembangkan algoritma perankingan dinamis $O(N+M)$ dan integrasi **Web Push Notification**.

DevOps & System Administrator

Docker + Nginx

Tanggung Jawab Utama:

  • Deployment ke server **Linux VM**, jaringan **Tailscale**, dan domain SSL di **Cloudflare**.
  • Menyiapkan sistem **backup database harian** otomatis jam 02:00 dan modul **monitoring server**.
